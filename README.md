# Mitron FM

Desi radio for car browsers (built for the Tesla in-car browser). Pick a language — Telugu, Hindi, Tamil, Malayalam, Kannada, Punjabi, Marathi, Bengali, Gujarati, Urdu, Odia, Bhojpuri, Konkani, Assamese or Devotional — and tap a station.

- Single static page: `index.html`, no build step.
- Station lists come live from the public [Radio Browser](https://www.radio-browser.info) directory; only secure (https) streams are shown, since car browsers block insecure audio.
- Favourites and last station are kept in the browser's local storage.

Live: https://srimukh99.github.io/mitron-fm/
